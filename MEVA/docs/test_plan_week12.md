# MEVA 테스트 계획서 test_plan_week12

## 1. 기능별 테스트 케이스 설계

각 모듈별로 필요한 동작이 제대로 수행되는지 확인
입력 처리, 그래프 표시, 결과 갱신, DB 연동 등 핵심 기능 위주로 테스트 진행

### InputPanel
- 직경/게이지 길이 입력값이 정상적으로 파싱되는지 확인
- CSV 파일 선택 시 파일 경로가 정상 표시되는지 확인
- Reset 수행 시 모든 입력 필드 초기화되는지 검증
- Preset 저장/삭제 기능이 정상 동작하는지 확인

### GraphPanel
- 엔지니어링/트루 스트레스-스트레인 곡선이 정상적으로 렌더링되는지 확인
- UTS, 항복점 등 주요 지표 표시 기능이 정상 작동하는지 확인
- 탄성/소성 영역 등 그래프 오버레이가 맞게 출력되는지 확인
- 줌/리셋 버튼이 그래프 상태에 맞게 동작하는지 확인

### ResultPanel
- updateResults 호출 시 테이블 데이터가 정확히 갱신되는지 확인
- updateValue / updateValueByProperty 로 개별 값 수정이 정상 동작하는지 확인
- clearResults 수행 시 모든 값이 "-"로 초기화되는지 확인
- CSV 저장 기능이 정상적으로 파일을 출력하는지 확인

### LoadExperimentDialog
- DB에 저장된 실험 목록이 테이블에 정상 로드되는지 확인
- 실험 선택 후 불러오기 버튼 또는 더블 클릭으로 정상 로드되는지 확인
- 삭제 기능 사용 시 DB와 리스트가 동기화되는지 확인
- 실험 정보가 누락되지 않고 올바르게 표시되는지 확인

## 2. 통합 테스트 시나리오

개별 기능이 아닌, 사용자 입장에서 실제 사용 흐름을 기준으로 전체 동작을 검증

### 시나리오 1 — CSV 로드 후 계산 및 결과 저장
1. CSV 불러오기 → 입력값 정상 파싱
2. Calculate 실행 → 그래프 및 결과 테이블 자동 업데이트
3. 그래프 표시 요소(UTS, 항복점 등) 정상 출력 확인
4. ResultPanel에서 Save Results → CSV 파일 생성 확인

### 시나리오 2 — DB에 저장된 실험 불러오기
1. LoadExperimentDialog 실행 → 실험 목록 표시
2. 실험 선택 후 로딩 → InputPanel 자동 입력 확인
3. Calculate 실행 → 그래프/결과가 일관되게 재생성되는지 검증

### 시나리오 3 — 실험 삭제
1. 삭제할 실험 선택
2. 삭제 버튼 클릭 → DB에서 제거
3. 목록 새로고침 후 삭제가 반영됐는지 확인

## 3. 테스트 자동화 계획

자동화가 가능한 범위와 수동 테스트가 필요한 범위를 구분하여 정리

### 자동화 대상 (JUnit)
- MaterialDatabase: 재료 정보 조회/추가 테스트
- 데이터 검증 로직: 입력값 검증, 범위 검사 등
- ExperimentDAO: insert/select/delete 동작 테스트 (H2 등 테스트 DB 사용 시)
- 계산 로직이 별도 모듈로 분리된 경우 해당 부분 단위 테스트 수행

### 자동화가 어려운 항목 (수동 테스트)
- Swing 기반 UI 요소 (버튼, 테이블 렌더링, 다이얼로그)
- 그래프 렌더링(zoom, overlay, 마우스 인터랙션)
- 사용자 입력 흐름 기반 시나리오 테스트

### CI 적용 방향
- GitHub Actions로 빌드 + 테스트 자동 실행
- PR 시 모든 테스트 자동 검증
- 코드 변경 시 계산 로직/DB 로직 회귀 테스트 수행
